# SciDocs

https://mh-studioz.github.io/scidocs/

SciDocs is a browser-based scientific document workbench for writing LaTeX — math, physics, chemistry, biology and quantum notation with live preview and PDF export. Everything runs locally in the browser.

## Text → LaTeX

The plain-English converter is a local, rule-based helper, not an AI service. It rewrites phrases like “x squared plus y squared” or “integral from 0 to infinity of x squared dx” into LaTeX instantly, and never sends your text anywhere.
