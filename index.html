What the preview supports

SciDocs renders a fast browser preview, not a complete TeX distribution.

Works well

Core math and KaTeX commands, fractions, roots, integrals, matrices, Greek letters, sections, lists, tables, links, common text formatting, custom macros and the built-in science notation.

Not a full LaTeX engine

Arbitrary packages, BibTeX and citation styles, \input or multi-file projects, exact journal page layout, custom fonts and every TikZ feature are outside the preview. Unsupported commands may appear as text or be ignored.

For a submission that depends on those features, download the .tex file and compile it in your TeX editor or Overleaf. The preview is intentionally fast and fully local; it does not upload your document.

The syntax banner reports structural problems it can detect.

SciDocs user guide

Write, preview and export a scientific document without a backend.

1. Write in the editor

Type LaTeX in the left editor. The preview updates automatically. Use Compile to refresh immediately, or Export PDF when the document is ready.

2. Math mode is required for commands

Commands such as \sigma only render inside math mode. Outside math, LaTeX treats the command as ordinary text.

\sigma * 8          → text: “\sigma * 8”
$\sigma * 8$       → inline math
$$\sigma * 8$$     → display math

If you already typed a formula outside math, wrap the whole expression in dollar signs. Examples:

  • $\sigma * 8$ for inline math.
  • $$\sigma * 8$$ for a centered display equation.
  • \begin{equation} \sigma * 8 \end{equation} for a numbered equation.

3. Insert symbols from the Symbol Lab

  1. Put the cursor where the symbol belongs.
  2. Type /sigma in the Symbol Lab search. \sigma and sigma also work.
  3. Tap or click the result.

If the cursor is outside math, SciDocs automatically wraps the symbol in $…$. Inside math or a math environment, it inserts the raw command. Document structures such as sections and tables are never wrapped.

4. Check errors before exporting

The banner under the editor reports unbalanced braces, dollar signs and environments. When it shows an issue, use Go to line to jump to it. The Info button explains which LaTeX features the browser preview supports.

5. Save, restore and share

Projects autosave to this browser. Open History for snapshots, restore an earlier version, or export a JSON backup. Share puts the document inside a link; opening it creates a local (shared) project.

6. Keyboard shortcuts

Ctrl/Cmd + Enter compile · Ctrl/Cmd + S save · Ctrl/Cmd + Space command suggestions · Alt + / fallback when Spotlight captures Cmd + Space · Ctrl/Cmd + K Text → LaTeX.
